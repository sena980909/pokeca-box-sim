# 포켓몬카드 박스깡 시뮬레이터

일본판 포켓몬 카드 인기 박스 15종의 개봉 조사 봉입률로 팩·박스를 가상 개봉하는 웹 페이지입니다.

- 배포: https://pokeca-box-sim.vercel.app
- 정적 페이지(`index.html` + `data.js`) — 빌드 과정 없음

## 기능

- 팩 1개 / 박스 1개 / 10박스 / 100박스 개봉
- 목표 카드가 나올 때까지 개봉 (몇 박스·얼마 걸렸는지)
- 세트별 봉입률 표, 박스 기대값과 회수율
- 누적 기록: 쓴 돈, 뽑은 카드 가치, 등급별 실제 vs 기대 매수, 베스트 풀
- 비용 기준 전환: 박스 시세 / 정가
- 카드 가치 기준 전환: 샵 판매가 / 매입가(가격대별 매입률로 추정, `data.js`의 `BUY_BANDS`)
- 엔 / 원화 표시 (환율 직접 입력 가능), 설정은 브라우저에 저장

## 수록 세트

30th CELEBRATION, ポケモンカード151, インフェルノX, テラスタルフェスex, 超電ブレイカー, ロケット団の栄光, MEGAドリームex, VSTARユニバース, ブラックボルト, ホワイトフレア, メガブレイブ, ムニキスゼロ, ニンジャスピナー, アビスアイ, ストームエメラルダ

## 데이터

- 봉입률은 팬 개봉 조사(トレカの地図, ポケゲトちゃんねる, ポケカ当たり 등) 추정치이며 공식 수치가 아닙니다.
- 시세는 2026년 9월 기준 샵 판매가(엔)입니다. 매입가는 보통 판매가의 50~70%입니다.
- 세트 데이터와 시세는 `data.js`에 있습니다. 시세를 갱신할 때는 이 파일만 고치고 `PRICE_DATE`를 바꾸면 됩니다(30일이 지나면 화면에 경고 표시). 박스당 봉입률은 `topSlots({MUR:.02, SAR:.28}, .10)`처럼 조사 수치를 그대로 넣으면 되고, 두 번째 값은 2장 박스 비율입니다.
